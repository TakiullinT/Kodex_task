# Sales Analytics CLI / Kodex Task

Консольное приложение на C# (.NET 10) для асинхронной обработки данных о продажах из CSV-файлов и генерации аналитических отчетов в формате JSON.

## Особенности проекта

* **Асинхронность и многопоточность:** Использование `async/await` для I/O операций (чтение CSV, запись JSON) и `Parallel.ForEach` / `PLINQ` для вычислительно сложных задач (агрегация данных).

* **Надежная архитектура:** Применение паттерна Dependency Injection (`Microsoft.Extensions.DependencyInjection`) для слабого связывания компонентов.

* **Иммутабельность:** Использование современных возможностей C# — `record` и `init`-свойств для защиты данных от случайных мутаций (Data Transfer Objects).

* **Отказоустойчивость:** Обработка поврежденных строк в CSV, защита от пустых файлов и некорректных аргументов командной строки.

* **Тестирование:** Покрытие 20+ тестами, включая Unit-тесты, интеграционные тесты и проверку DI-контейнера.

## Технологии

* **Framework:** .NET 10.0

* **Тестирование:** xUnit, Moq

* **Сериализация:** System.Text.Json

* **DI Контейнер:** Microsoft.Extensions.DependencyInjection

## Структура решения

* `Kodex_sol/` — основной проект консольного приложения.

  * `Models/` — доменные модели и DTO (`Sale`, `AnalyticsResult`, `CommandLineOptions`).

  * `Services/` — бизнес-логика, чтение, запись и парсинг.

* `Kodex_tests/` — проект с модульными и интеграционными тестами.

## Запуск и использование

Приложение запускается из командной строки и принимает набор аргументов для настройки фильтрации и путей к файлам.

### Примеры запуска

**Базовый запуск (обработка всего файла):**

```
dotnet run --project Kodex_sol --input="sales.csv" --output="result.json"

```

**Запуск с фильтрацией по датам:**

```
dotnet run --project Kodex_sol --input="sales.csv" --start_date="2022-01-01" --end_date="2022-01-31"

```

## Запуск тестов

Проект покрыт unit- и интеграционными тестами. Для их запуска выполните команду в корневой директории (там, где находится файл `.sln`):

```
dotnet test

```
